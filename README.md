# Ingliz Tili Lug'at O'rganish va Aqlli Test Dasturi (Vocabulary App)

Zamonaviy va interaktiv ingliz tili so'zlarini o'rganish, qidirish hamda xotirani mustahkamlovchi intellektual test (Requeue algoritmi) tizimi.

## 🚀 Asosiy Imkoniyatlar

1. **Kitoblar va Bo'limlar (Units & Books):**
   - **Destination B1:** Topic Vocabulary, Phrasal Verbs, Prepositional Phrases, Word Formation va Word Patterns bo'yicha to'liq guruhlangan lug'atlar.
   - **4000 Essential English Words:** Har bir Unit bo'yicha saralangan so'zlar va ularning o'zbekcha tarjimalari.

2. **3 Bosqichli Qidiruv Tizimi:**
   - **Global Search (`Ctrl+K`):** Barcha kitoblar va unitlardagi 1,600+ dan ortiq so'zlarni tezkor qidirish, filtratsiyalash va audiosini tinglash.
   - **Book-Level Search:** Tanlangan kitob bo'yicha so'zlar va unitlarni filtrlash.
   - **Unit-Level Instant Filter:** Tanlangan Unit sahifasida faqat shu unit tarkibidagi so'zlarni real vaqt rejimida qidirish va faqat topilgan so'zlar bilan Flashcards yoki Quiz boshlash.

3. **O'rganish Rejimlari:**
   - **Fleshkartalar (Flashcards):** 3D flip-card animatsiyasi, audio talaffuz va kartalarni aralashtirish (shuffle).
   - **Aqlli Test (Interactive Quiz):** Noto'g'ri belgilangan so'zlarni dars davomida yana takroran so'rab xotiraga mixlovchi qayta so'rash (requeue) algoritmi.
   - **Statistika va Tarix:** Test natijalari, xatolar tahlili va o'zlashtirish foizlari.

4. **Audio Talaffuz (Web Speech API):**
   - Har bir so'zning to'g'ri inglizcha talaffuzini eshitish imkoniyati.

## 🛠 Texnologiyalar

- **Frontend:** React 18, TypeScript, Vite
- **Uslublar (Styling):** Tailwind CSS, Lucide React Icons
- **Animatsiyalar:** Motion (Framer Motion)
